# Обзор российских платформ для работы с Git

## Общие сведения
Рассмотрены GitFlic, Deckhouse Code и Gitlife Enterprise,
включённые в Единый реестр российского ПО.
Это платформы для организации разработки на основе Git,
а не замены самой системы контроля версий.

## GitFlic
Запись в реестре: №15861.

Назначение: хранение исходного кода и совместная разработка.

Возможности: Git-репозитории, команды, задачи, запросы на слияние,
автоматические проверки и сборки, реестр пакетов.
Предусмотрены облачное использование и установка на своём сервере.

Преимущества: можно выбрать способ размещения проекта,
объединить хранение кода и автоматизацию разработки.

Ограничения: собственная установка требует администрирования.
При переносе с GitHub нужно адаптировать конфигурацию CI:
файл GitHub Actions не является универсальным.

Источник: https://gitflic.ru/

## Deckhouse Code
Запись в реестре: №27871.

Назначение: хранение кода и управление жизненным циклом ПО.

Возможности: совместная работа с исходным кодом,
непрерывная интеграция и доставка приложений.
Поддерживается размещение в облаке и инфраструктуре организации.

Преимущества: объединение работы с кодом и CI/CD,
возможность развёртывания в инфраструктуре компании.

Ограничения: развёртывание и сопровождение требуют ресурсов.
Для небольшого учебного проекта необходимо оценить,
оправдана ли такая инфраструктура.

Источник:
https://deckhouse.ru/blog/deckhouse-code-included-in-the-unified-register-of-russian-software/

## Gitlife Enterprise
Запись в реестре: №29396.

Назначение: управление разработкой и цифровыми активами компании.

Возможности: управление кодом на основе Git,
совместная работа с поддержкой Scrum и Kanban,
CI/CD, сканирование кода и аналитика.
Предусмотрена установка на сервере заказчика.

Преимущества: модульная организация и объединение инструментов
разработки с управлением проектами и аналитикой.

Ограничения: установка на сервере требует администрирования.
Стоимость и состав поставки необходимо согласовывать с поставщиком.
Для учебного проекта часть возможностей может быть избыточной.

Источник: https://enterprise.gitlife.ru/index.php

## Вывод
Платформы позволяют организовать работу с Git и автоматизацию
разработки. При выборе нужно учитывать способ размещения,
условия лицензирования, необходимые функции и затраты
на сопровождение. Включение в реестр само по себе
не гарантирует отсутствие уязвимостей или сбоев.

Ограничения применительно к учебному проекту являются
выводами сравнительного анализа.
