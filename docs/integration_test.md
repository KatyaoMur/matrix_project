# Тестирование интеграции

## Условия проверки

Windows, Python 3.14.7, pytest 9.1.1.
Команда запуска: python -m pytest -v.
Интеграционные тесты используют отдельные временные каталоги.

## Сценарии и результаты

| Сценарий | Ожидаемый результат | Итог |
|---|---|---|
| Файловая цепочка для 3 x 3 | Матрица 3 x 3, положительных 5, текст сформирован | Пройден |
| Файловая цепочка для 1 x 1 | Матрица 1 x 1, положительных 1, текст сформирован | Пройден |
| Размер n равен 0 | ValueError, файл результата не создан | Пройден |
| Размер m отрицательный | ValueError, файл результата не создан | Пройден |
| Размер n передан строкой | ValueError, файл результата не создан | Пройден |
| Поле m отсутствует | ValueError, файл результата не создан | Пройден |
| Повреждённый JSON | JSONDecodeError, файл результата не создан | Пройден |
| Файл задания отсутствует | FileNotFoundError, файл результата не создан | Пройден |
| Запуск main с вводом 3 и 3 | Код 0, оба файла созданы, в выводе количество 5 | Пройден |

Тесты файловой цепочки также проверяют размеры матрицы
и сохранение исходного значения sin(1.5) после сериализации.

## Итог

9 интеграционных и 6 исходных тестов прошли успешно.
Итог запуска: 15 passed in 0.15s.

Ручной запуск для матрицы 3 x 3 подтвердил создание файлов
request.json и result.json и вывод 5 положительных элементов.

Работа выполнялась одним разработчиком.
Условие задания о конфликте при совместной работе нескольких
разработчиков к текущему этапу не применяется.

Добавлено 14 проверок:
