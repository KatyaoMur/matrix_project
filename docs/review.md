## Проверка логики
Матрица рассчитывается по формуле sin(i + j / 2).
Индексы начинаются с 1, аргумент синуса задаётся в радианах.
Подсчёт выполняется по условию value > 0.
Для матрицы 3 × 3 получено 5 положительных элементов.

## Результаты проверок
- python -m flake8 src tests — без замечаний.
- python -m pytest -v — 6 тестов прошли.
- Ручной запуск python src/main.py с размерами 3 × 3
  подтвердил ожидаемую матрицу и 5 положительных элементов.
- GitHub Actions успешно выполнил установку зависимостей,
  проверку стиля и запуск тестов.

## Оставшиеся замечания
Расчёт дублируется в main.py и matrix_sin.py.
Рекомендуется использовать общие функции в консольной программе,
чтобы тесты проверяли ту же реализацию, которая запускается пользователем.
Ввод нецелых значений не обработан.
Автоматические тесты не покрывают интерактивный ввод,
отрицательные размеры и отдельную проверку исключения нуля
из числа положительных элементов.
