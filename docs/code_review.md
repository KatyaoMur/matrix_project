## Исправления в ходе работы

Устранено дублирование вычислений в main.py.
Добавлены проверки размеров, структуры и версии сообщений.
Расчёт выделен в дочерний процесс с ограничением времени.
Настроены единые параметры flake8 и автоматический контроль покрытия.

## Ограничения и рекомендации

Фиксированные имена request.json и result.json рассчитаны
на последовательный запуск одной программы.
Для параллельных заданий следует выделять отдельный каталог на запрос.

Таймаут по умолчанию равен 5 секундам.
Для больших матриц его необходимо выбирать с учётом нагрузки.

Проверка результата контролирует наличие списка строк матрицы
и целочисленного счётчика. Для внешних производителей данных
следует дополнительно проверять числовые элементы, прямоугольность
матрицы и согласованность счётчика с её содержимым.

Покрытие строк не доказывает отсутствие всех ошибок.
Дополнительное развитие тестов возможно для некорректных результатов
и нескольких одновременных заданий.
