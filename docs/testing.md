# План тестирования

## Цель
Проверить размеры и значения матрицы, подсчёт положительных
элементов и форматирование результата.

## Окружение
Python 3.14, pytest и flake8.
Локальная проверка — Windows, GitHub Actions — Ubuntu.

## Подготовка
Из корня проекта выполнить:
    python -m pip install -r requirements.txt

## Автоматические тесты
Файл: tests/test_matrix_sin.py.

| Проверка | Ожидаемый результат |
| --- | --- |
| Матрица 3 × 3 | 5 положительных элементов |
| Матрица 1 × 1 | 1 положительный элемент |
| Матрица 1 × 2 | 2 положительных элемента |
| 0 строк, 5 столбцов | Пустая матрица, 0 положительных элементов |
| Матрица 2 × 4 | 2 строки по 4 элемента, первый равен sin(1.5) |
| Форматирование [1.234, 2.0] | Текст [1.23, 2.0] |

## Запуск проверок
Из корня проекта выполнить:
    python -m flake8 src tests
    python -m pytest -v

Критерий успеха: flake8 без замечаний, все 6 тестов проходят.

## Ручная проверка
Запустить:
    python src/main.py

Ввести 3 строки и 3 столбца.
Ожидается матрица и сообщение о 5 положительных элементах.

## Ограничения
Автоматические тесты не проверяют интерактивный ввод main.py.
Тест с нулевым числом строк проверяет функцию build_matrix.
Буквенный ввод и отрицательные размеры тестами не покрыты.

## Проверки на GitHub
При push и Pull Request запускается Python CI:
установка зависимостей, flake8 и pytest.
Критерий успеха — зелёный статус задания checks.
