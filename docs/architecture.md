# Архитектура проекта

## Назначение
Программа создаёт матрицу заданного размера по формуле
a[i][j] = sin(i + j / 2), где индексы начинаются с 1,
и подсчитывает строго положительные элементы.
Аргумент синуса задаётся в радианах.

## Структура проекта
- src/main.py — консольная программа: ввод размеров, расчёт и вывод.
- src/matrix_sin.py — функции расчёта матрицы и подсчёта
  положительных элементов, используемые в автоматических тестах.
- src/report.py — функция преобразования матрицы в текст.
- tests/test_matrix_sin.py — автоматические тесты.
- docs/ — техническое задание и документация.
- requirements.txt — зависимости для тестирования и проверки стиля.
- .github/workflows/ci.yml — автоматические проверки GitHub Actions.
- .github/ISSUE_TEMPLATE/bug_report.md — шаблон сообщения об ошибке.
- .github/PULL_REQUEST_TEMPLATE.md — шаблон запроса на слияние.

## Основные функции
build_matrix(rows, columns) возвращает матрицу заданного размера.

count_positive(matrix) подсчитывает элементы со значением больше нуля.

format_matrix(matrix) возвращает текстовое представление матрицы
с округлением элементов до двух знаков после запятой.

## Особенности реализации
В текущей версии main.py выполняет расчёт самостоятельно.
Модуль matrix_sin.py содержит отдельную реализацию для тестирования.
Автоматические тесты проверяют функции модулей matrix_sin и report;
интерактивный ввод main.py проверяется вручную.

## Автоматические проверки
При отправке изменений и создании Pull Request GitHub Actions
устанавливает зависимости, запускает flake8 и pytest.
Ошибка любого этапа приводит к неуспешному завершению проверки.
